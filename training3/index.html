2️⃣ Live System Demonstration

2️⃣ ការបង្ហាញផ្ទាល់លើផ្ទាំងកញ្ចក់បញ្ចាំង (Live Demo)

Live end-to-end demonstration on the projector screen just like practiced before: creating a test order, printing waybills, and scanning statuses.
ការបង្ហាញផ្ទាល់នៅលើកញ្ចក់បញ្ចាំង (Projector) ដូចដែលបានហាត់សមពីមុន៖ បង្កើតបុងសាកល្បង ព្រីនស្ទីគ័រ និងស្កេនតាមដំណាក់កាល។
LIVE DEMO WORKFLOW Head Office Projector Demo
1. Create a Test Order: ១. បង្កើតបុងសាកល្បង (Create a Test Order)៖ Create a sample bill live on the system with Sender, Receiver, COD, and weight. បង្កើតបុងគំរូជាក់ស្តែងនៅលើប្រព័ន្ធ ដោយបញ្ចូលឈ្មោះអ្នកផ្ញើ អ្នកទទួល ទឹកប្រាក់ COD និងទម្ងន់។
2. Print the Bill (Waybill): ២. ព្រីនស្លាកលេខកូដបារ (Print Waybill Label)៖ Use the thermal printer brought from PNPP014 to print out the real adhesive barcode sticker. ប្រើប្រាស់ម៉ាស៊ីនព្រីនដែលយកមកពីសាខា PNPP014 ដើម្បីព្រីនស្ទីគ័រលេខកូដបារជាក់ស្តែង។
3. Accept & Scan (Status 210): ៣. ស្កេនទទួលទំនិញ (Accept & Scan Status 210)៖ Scan the barcode into the mobile app as "Received / Pickup Done". ស្កេនលេខកូដបារចូលក្នុងប្រព័ន្ធទូរស័ព្ទដៃជា "បានទទួលទំនិញ / Pickup Done" (Status 210)។
4. Transit / Handover (Status 306): ៤. ផ្ទេរទំនិញទៅ Hub/Mega (Transit Status 306)៖ Demonstrate how to put parcels into manifests and send to Mega / Hub. បង្ហាញពីរបៀបបញ្ចូលទំនិញក្នុងបញ្ជីរថយន្ត និងផ្ទេរទៅកាន់ Mega / Hub (Status 306)។
5. Assign & Deliver (Status 402 ➔ 410): ៥. ចាត់តាំង និងចែកទំនិញ (Assign & Deliver 402 ➔ 410)៖ Show how to assign a driver (Status 402), dispatch out for delivery (Status 400), and complete final delivery confirmation (Status 410). បង្ហាញពីការចាត់តាំងអ្នកដឹក (Status 402) ចេញចែក (Status 400) និងស្កេនបញ្ចប់ការដឹកជញ្ជូនជោគជ័យ (Status 410)។

3️⃣ Staff Hands-on Practice Session

3️⃣ វគ្គអនុវត្តផ្ទាល់ដៃសម្រាប់បុគ្គលិក

Let staff and trainees try creating orders, printing labels, and scanning on test accounts so they master their daily operational duties.
ឱ្យបុគ្គលិកទាំងអស់ចូលប្រើគណនីសាកល្បង បង្កើតបុង ព្រីនស្លាក និងស្កេនដោយផ្ទាល់ដៃ ដើម្បីធានាភាពស្ទាត់ជំនាញក្នុងការបំពេញការងារប្រចាំថ្ងៃ។
PRACTICE CHECKLIST Individual Hands-on Tasks
Task A — Test Account Login: លំហាត់ A — ចូលប្រើប្រាស់គណនីសាកល្បង៖ Every participant logs into OPS Web and Mobile Courier App using assigned training credentials. បុគ្គលិកគ្រប់រូបចូលប្រើប្រាស់ប្រព័ន្ធ OPS Web និងកម្មវិធីទូរស័ព្ទដៃដោយប្រើគណនីបណ្តុះបណ្តាល។
Task B — Create Individual Test Bill: លំហាត់ B — បង្កើតបុងទំនិញសាកល្បងដោយខ្លួនឯង៖ Each trainee creates 1 pickup order and 1 drop-off counter order with complete parcel details. បុគ្គលិកម្នាក់ៗបង្កើតបុងទៅយក (Pickup) ១ និងបុងផ្ញើនៅបញ្ជរ ១ ដោយបញ្ចូលព័ត៌មានពេញលេញ។
Task C — Label Printing & Scanning Run: លំហាត់ C — ព្រីនស្ទីគ័រ និងស្កេនបញ្ចប់ដំណើរការ៖ Practice test label printing, scan Status 210, assign driver (402), and complete simulated delivery (410). អនុវត្តព្រីនស្លាកកូដបារ ស្កេន Status 210 ចាត់តាំងអ្នកដឹក (402) និងស្កេនបញ្ចប់ការដឹក (410)។
Task D — Q&A & Error Handling: លំហាត់ D — សំណួរ-ចម្លើយ និងការដោះស្រាយបញ្ហា៖ Address common field errors (Status 420 store waiting, 472 issue resolution, 520 customer return) and best practices. 解ឆ្លើយសំណួរអំពីបញ្ហាជួបប្រទះ (Status 420 រង់ចាំ, 472 ដោះស្រាយបញ្ហា, 520 ភ្ញៀវបង្វែរទំនិញ) និងបទពិសោធន៍ល្អៗ។
